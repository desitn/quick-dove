# Quick Firmware + 插件分析Skill

## Skill概述
这是一个专门用于分析和处理Quick Firmware + VSCode插件的自动化技能，能够帮助理解和修改这个嵌入式固件开发辅助工具。

## 核心能力

### 1. 项目结构分析
- 识别VSCode插件的标准目录结构
- 分析`package.json`配置文件
- 理解插件的激活事件和贡献点
- 识别核心依赖包的作用

### 2. 功能模块识别
- **固件管理模块**: 固件列表浏览、多格式支持
- **编译支持模块**: 构建命令执行、脚本支持
- **设备管理模块**: USB设备扫描、列表显示
- **界面交互模块**: 侧边栏视图、状态栏操作

### 3. 代码分析能力
- 解析extension.js主逻辑
- 理解TreeView数据提供者模式
- 分析命令注册和事件处理
- 识别异步操作和Promise使用

### 4. 依赖管理
- 分析npm依赖包的作用
- 识别可移除的冗余依赖
- 理解各依赖包的技术用途
- 建议合理的依赖精简方案

## 工作流程

### 问题分析阶段
1. **需求理解**: 准确理解用户的修改需求
2. **现状评估**: 分析当前插件的功能和结构
3. **影响评估**: 评估变更对现有功能的影响
4. **风险识别**: 识别潜在的技术风险点

### 执行阶段
1. **渐进式修改**: 采用先代码后文件的清理策略
2. **功能验证**: 确保核心功能不受影响
3. **依赖清理**: 移除不必要的npm包
4. **文档更新**: 同步更新相关文档

### 验证阶段
1. **语法检查**: 验证代码语法正确性
2. **功能测试**: 确认核心功能正常
3. **依赖验证**: 检查依赖关系完整性
4. **结构审查**: 确保项目结构整洁

## 关键技术点

### VSCode插件开发
- Extension激活机制
- TreeView API使用
- 命令注册和执行
- 配置项管理

### Node.js技术栈
- 异步编程模式
- 文件系统操作
- 进程管理

### 项目最佳实践
- 模块化设计原则
- 依赖最小化
- 文档同步更新
- 版本控制规范

## 决策指导原则

### 保留vs删除判断
- **保留**: 核心功能相关的代码和依赖
- **保留**: 用户明确要求的功能
- **保留**: 系统必需的配置文件（如.lingma）
- **删除**: 冗余的功能模块
- **删除**: 无用的依赖包
- **删除**: 空的目录结构

### 兼容性考虑
- 保持现有API接口稳定性
- 确保向后兼容性
- 维护用户配置的连续性

## 输出规范

### 文档要求
- 创建详细的变更记录(Agent.md)
- 提供清晰的操作步骤
- 记录关键决策点
- 给出后续维护建议

### 代码质量
- 保持代码整洁和可读性
- 添加必要的注释说明
- 遵循一致的编码风格
- 确保错误处理完整性

## 使用场景
适用于VSCode插件的功能精简、模块化解耦、依赖优化等维护工作，特别适合需要保持核心功能完整性的重构任务。
